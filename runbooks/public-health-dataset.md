# Runbook: public health dataset

The dataset in `deliverables/public-health-dataset/` is written by `export_public_health_dataset.py` and checked by `python3 -m lovs.snapshot_contract --check-dataset`, which `release_snapshot.py --check` runs. Each row below starts from the message a maintainer sees.

| Symptom | Check | Fix |
|---|---|---|
| The export stops: "source field 'X' names a case class but is not in the public dataset's metric vocabulary" | Read field X in the newest reviewed promotion and in `data/bundibugyo-2026/manifest.json`. The message names the source. | Classify X in `export_public_health_dataset.py`: `CUMULATIVE_METRIC_BY_FIELD` for a running total, `METRIC_BY_FIELD` for another named series, or `OWN_NAME_CASE_FIELDS` to keep its own name. If its name uses a country or province word the dataset does not know, add the word to `_COUNTRY_BY_FIELD_TOKEN` in `lovs/snapshot_contract.py`. Add a test, then rerun the release check. |
| `--check-dataset`: "a source gives each cumulative series one value" or "each 24-hour series one value" | The message names both rows. A cumulative metric at `COD; UGA` is the same series as its `country_scope_` metric. | Usually a DRC term and a two-country term are filed together. Fix the field's geography, or add a reviewed label with the source's own evidence to `REVIEWED_SOURCE_FIELD_LABELS` in `lovs/snapshot_contract.py`. Never change a value. |
| `--check-dataset`: "it is the DRC figure, so label it 'COD'" | The row equals the same source's DRC-named term while the source also reports Uganda figures. | Add the row to `REVIEWED_SOURCE_FIELD_LABELS` with location `COD` and a comment giving the evidence. |
| `--check-dataset`: "package manifest records <input> as sha256 ... but the file is ..." | An input changed after the export, or was left out of the commit. `data/live-bdbv-2026-output.json` carries a wall-clock date, so a release check run on a later day rewrites it. | Commit the regenerated input together with the dataset, or restore the committed input and rerun `python3 export_public_health_dataset.py` and `python3 -m lovs.public_exports` before committing. |
| Someone proposes changing the package manifest's `schema_version` | `lovs/semantic_freshness_gate.py` enforces its per-artifact checks only when that value is 2. | Keep it at 2. Version the dataset's content through `lovs-public-health-dataset.schema.json` instead. |
