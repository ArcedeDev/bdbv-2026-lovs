# Licensing

This public repository holds the LOVS evidence package for the 2026 Bundibugyo virus outbreak and the code that builds it: the method modules in `lovs/`, the scripts at the top level and in `tools/` and `examples/`, and `tests/`.

## Code

All code in this repository is licensed under Apache License 2.0. See [`LICENSE`](LICENSE).

## Original Public Artifacts

Original authored public prose, charts, HTML, PDFs, data files, and generated publication artifacts are licensed under Creative Commons Attribution 4.0 International (CC BY 4.0), excluding third-party source material, publisher-owned excerpts, and data whose upstream terms are more restrictive.

Model outputs that this repository publishes are generated publication artifacts under the same licence. They sit outside the public export contract listed in `README.md` (see `LIMITATIONS.md`) and include the vaccine field-effectiveness scenarios in [`data/vaccine-field-effectiveness/`](data/vaccine-field-effectiveness/), which are scenarios for situational awareness, not measured effectiveness and not clinical or vaccine advice. Weekly forecast quantiles stay private; each registered week publishes only its commitment hash (`docs/weekly-forecast-loop.md`).

## Third-Party Material

Third-party outbreak reports, source facts, and cited datasets retain their own terms. This repository does not redistribute Arcede's private source captures, restricted raw publisher bytes, or internal engineering process records; those stay in local stores outside the repository.

Per-item source attribution is recorded in [`CITATIONS.md`](CITATIONS.md), [`data/public_source_manifest.json`](data/public_source_manifest.json), and [`data/public_source_index.csv`](data/public_source_index.csv).
